## 권장 발행 순서

1. **페이지가 실제로 뜨는지 먼저 확인** — `{{LIVE_URL}}`을 열어 마켓 탭·언어 전환이 동작하는지 1분 점검 (Pages 배포 직후에는 첫 반영에 1~2분 걸릴 수 있음).
2. **스레드 4편 연속 게시** — 1/4에는 링크를 넣지 않고, 4/4에만 링크를 둔다.
3. **X는 트윗 1(고정) → 트윗 2(마켓) 순서**로, 두 번째는 첫 글에 답글로 붙여도 된다.

## 지켜야 하는 것 (법적 4대 기준)

1. **사칭 금지** — OpenAI·Anthropic 공식, 공식 제휴·인증이라고 쓰지 않는다. "ChatGPT·Claude에 붙여넣으면 동작"처럼 호환 도구로만 표현한다.
2. **수익 보장·과장 금지** — "수익", "보장", "무조건" 류 표현 금지. 상품의 효익은 구성과 분량으로만 설명한다.
3. **자체 제작 이미지·음원만** — 사이트 캡처와 `images/shop-*.svg`만 사용한다. 타사 로고·스크린샷·차트를 쓰지 않는다.
4. **가격·링크 투명 표기** — 9,900원(정가 29,000원), 4,900원(정가 9,900원)과 래피드 링크를 원문 그대로 적고, 디지털 파일·실물 배송 없음·환불 조건을 함께 밝힌다.

각 언어 파일 끝의 체크 표가 이 기준의 판정 기록이다. 값이나 문구를 바꾸면 표도 같이 고친다.
